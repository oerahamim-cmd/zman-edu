# זמן לחינוך · מבט שבועי · שיחות אישיות (גרסת ענן: Vercel + Postgres)

אותה אפליקציה כמו `zman-weekly-app`, אבל בנויה לרוץ על שירותי ענן חינמיים, **בלי שרת משלכם ובלי תלות ב-IT של חותם**:

- **Vercel** מארחת את האתר ואת ה-API (פונקציות).
- **Postgres** שומר את הנתונים. הכי פשוט: Neon, שמתחבר ל-Vercel בכמה לחיצות.

אין תיעוד על תלמידים בשום מקום ששרת יכול לראות. מיפוי הכיתה נשאר רק בדפדפן של המחנכת.

## פריסה: שלושה צעדים (כ-15 דקות)

> אפשר לבקש ממני לבצע את הצעדים 2 ו-3 בשבילך, אחרי שתיכנסי ל-Vercel מהטרמינל (צעד 1).

### 1. חשבון Vercel והתחברות
1. נרשמים ב-[vercel.com](https://vercel.com) (אפשר עם גוגל או גיטהאב).
2. בטרמינל, בתיקייה הזו: `npx vercel login` ומאשרים בדפדפן.

### 2. יוצרים את הפרויקט ומחברים בסיס נתונים
1. `npx vercel` (בפעם הראשונה עונים: Link to existing project? **No**. שם הפרויקט, למשל `zman-weekly`. שאר השאלות: Enter). זה יוצר פריסת ניסיון.
2. בדשבורד של Vercel: הפרויקט ← **Storage** ← **Create Database** ← **Neon (Postgres)** ← אזור **Frankfurt (eu-central-1)** ← **Connect to project** (כל הסביבות). זה מוסיף לבד את `DATABASE_URL`.
3. מגדירים קוד הקמה: בפרויקט ← **Settings** ← **Environment Variables** ← `SETUP_CODE` = מחרוזת ארוכה ואקראית (לפחות 20 תווים) לכל הסביבות. **שומרים אותה אצלך**: היא גם מה שמאפשר ליצור את חשבון מנהלת התכנית וגם לאפס סיסמה שנשכחה.
4. (לא חובה) `PROGRAM_START` = תאריך של יום ראשון, למשל `2026-10-18`: תחילת השבוע הראשון בגרפים. אם לא מגדירים, השבוע הראשון הוא השבוע שבו נכנסו לאתר לראשונה.

### 3. עולים לאוויר
`npx vercel --prod`. בסוף מקבלים כתובת כמו `https://zman-weekly.vercel.app` (אפשר גם לחבר דומיין משלכם בהגדרות הפרויקט).

אחר כך:
1. פותחים את הכתובת ← לשונית "מנהלת התכנית" ← מזינים את `SETUP_CODE`, שם, דואל וסיסמה. זה יוצר את החשבון שלך.
2. ב"מובילות וקודים" מעתיקים את נוסח ההודעה לכל בית ספר ושולחים למחנכות (`docs/נוסח-הודעה-למשתתפות.md`).

## עדכון גרסה
משנים קבצים ומריצים שוב `npx vercel --prod`. הנתונים נשארים בבסיס הנתונים.

## הרצה מקומית (בלי ענן)

```bash
npm install
npm run dev       # הדגמה על http://127.0.0.1:3500 עם נתוני דוגמה בדויים (Postgres מובנה, בזיכרון)
npm test          # 41 בדיקות
```

בהדגמה: מנהלת התכנית `manager@example.org` / `demo-password-1234`, מחנכת "נועה כהן" (נעמי שמר) קוד 1185, מובילה "נטע רוזן" (נעמי שמר) קוד 1357. קודי ההצטרפות מודפסים בעליית השרת.

## מה שמור ואיפה

| מה | איפה |
|---|---|
| חשבונות, מבטים, ארגז כלים, יומן גישה | Postgres (Neon) |
| קודים אישיים | Postgres, מוצפנים (scrypt). לא ניתן לשחזר קוד, רק לאפס |
| מיפוי הכיתה | רק בדפדפן של המחנכת (localStorage). לא בשרת |
| טיוטת מבט שלא נשלח | רק בדפדפן של המחנכת |

**גיבוי:** ל-Neon יש שחזור לנקודת זמן (בתוכנית החינמית: ימים בודדים אחורה, בהגדרות הפרויקט ב-Neon). בנוסף: מנהלת התכנית מורידה את הייצוא (CSV) מדי פעם, בלשונית "ייצוא".

## החלטות שהחלטתי בלי אישור

1. **Postgres במקום SQLite**: ב-Vercel אין דיסק קבוע, ולכן קובץ SQLite לא ישמור נתונים. בבדיקות ובהרצה מקומית רץ אותו Postgres בתוך התהליך (PGlite).
2. **הגבלת ניסיונות כניסה נשמרת בבסיס הנתונים**: בענן כל בקשה יכולה לרוץ בתהליך אחר, וספירה בזיכרון לא הייתה עוצרת ניחוש קוד של ארבע ספרות. נבדק גם מול 30 ניסיונות מקבילים.
3. **איפוס סיסמה של מנהלת התכנית** נעשה במסך הכניסה בעזרת `SETUP_CODE`, ולא בפקודת שרת. מי שמכירה את הקוד (מי שמנהלת את הפרויקט ב-Vercel) יכולה לאפס. לכן הקוד חייב להישמר בסוד.
4. **הלוגואים של חותם ושל אורט נשארו.** העצמאות היא בתשתית (אירוח ובסיס נתונים), לא במיתוג. אפשר להסיר.
5. שאר ההחלטות כמו ב-`zman-weekly-app`: קוד הצטרפות לכל בית ספר (נפרד למובילה), שם בכניסה חוזרת נכתב ולא נבחר מרשימה, ברירת מחדל למובילה היא נתונים מצטברים בלבד.

## מגבלות ועלויות (לבדוק לפני שמתחילים)

- **תנאי השימוש של Vercel**: התוכנית החינמית (Hobby) מיועדת לשימוש אישי ולא מסחרי. תכנית של עמותה או ארגון עלולה להידרש לתוכנית Pro בתשלום (כ-20 דולר לחודש). כדאי לבדוק מול ההגדרות העדכניות של Vercel.
- **Neon בחינם**: 0.5GB, והבסיס "נרדם" אחרי כמה דקות בלי שימוש, כך שהכניסה הראשונה אחרי הפסקה איטית בשנייה-שתיים. לעשרות משתמשות זה מספיק.
- **פרטיות**: שמות מחנכות והערות חופשיות נשמרים אצל ספקי ענן זרים (Vercel ו-Neon; מומלץ לבחור אזור פרנקפורט). אין תלמידים בנתונים, אבל כדאי לוודא שזה מקובל על חותם ואורט.
- הסתרת ערכים קטנים מ-5 היא ברמת קטגוריה: מי שמחשבת הפרשים מול הסכום הכולל יכולה להסיק ערך מוסתר.
- אין שליחת דואל, ולכן אין "שכחתי קוד" עצמאי למחנכת: מנהלת התכנית מאפסת.
- **לא נבדק על Vercel עצמה** (אין לי חשבון): נבדק מקומית עם דימוי של הכניסה של Vercel (גוף בקשה מפוענח, כתובת לקוח מהכותרות, ניתוב לפי נתיב), ועם Postgres אמיתי רק דרך PGlite. הפריסה הראשונה היא גם הבדיקה האמיתית.
