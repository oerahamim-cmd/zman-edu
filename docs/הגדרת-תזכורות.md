# הגדרת התזכורות השבועיות

התזכורות כבר בנויות באפליקציה. כדי שיתחילו לצאת, צריך להגדיר ב-Vercel כמה ערכים, ולתזמן ריצה פעם בשעה.
כל ערוץ נדלק לבד ברגע שהערכים שלו מוגדרים. עד אז המחנכות יכולות לבחור תזכורת, וההגדרה נשמרת.

הערכים מוגדרים ב-Vercel: Project → Settings → Environment Variables, לסביבת Production. אחרי שינוי צריך Redeploy.

## 1. התראה בטלפון

1. במחשב, בתיקיית האפליקציה, מריצים פעם אחת:
   `npx web-push generate-vapid-keys`
2. מוסיפים ב-Vercel:
   - `VAPID_PUBLIC_KEY`: המפתח הציבורי (Public Key)
   - `VAPID_PRIVATE_KEY`: המפתח הפרטי (Private Key). סוד: לא לשתף ולא לשמור במאגר.
   - `VAPID_SUBJECT`: `mailto:` ואחריו כתובת מייל של התכנית, למשל `mailto:zman@tfi.org.il`

באייפון, התראות עובדות רק אחרי שהאפליקציה נוספה למסך הבית (iOS 16.4 ומעלה). הכניסה הראשונה מסבירה איך.

## 2. מייל

צריך תיבת מייל ששולחת דרך SMTP: למשל חשבון Google Workspace או Microsoft 365 של הארגון (עם סיסמת אפליקציה), או שירות שליחה כמו Resend או Brevo.

- `SMTP_URL`: כתובת השרת עם שם המשתמש והסיסמה, בצורה:
  `smtps://user%40domain.org:PASSWORD@smtp.example.com:465`
  (`%40` במקום `@` בשם המשתמש. בפורט 587 כותבים `smtp://` במקום `smtps://`.)
- `MAIL_FROM`: השולח שיופיע במייל, למשל `זמן לחינוך <zman@tfi.org.il>`
- `APP_URL`: הכתובת של האפליקציה, `https://zman-edu.vercel.app`

כתובת המייל של המחנכת נשמרת רק אם בחרה תזכורת במייל, ונמחקת כשהיא מכבה את המייל או כשהחשבון שלה מוסר.

## 3. ריצה פעם בשעה

התזכורות יוצאות מריצה שעתית לכתובת:
`https://zman-edu.vercel.app/api/cron/reminders`

- `CRON_SECRET`: מחרוזת ארוכה ואקראית (לפחות 20 תווים). רק מי שמכיר אותה יכול להפעיל את הריצה.

יש שתי דרכים לתזמן:

- **Vercel Pro:** מוסיפים ל-`vercel.json` את השורות:
  `"crons": [{ "path": "/api/cron/reminders", "schedule": "0 * * * *" }]`
  Vercel שולח את `CRON_SECRET` לבד. בתוכנית החינמית (Hobby) אפשר רק פעם ביום, וזה לא מספיק לבחירת שעה.
- **מתזמן חיצוני חינמי** (למשל cron-job.org): משימה שרצה כל שעה עגולה, שולחת GET לכתובת למעלה,
  עם הכותרת `Authorization: Bearer <CRON_SECRET>`.

## בדיקה

1. נכנסים כמחנכת, בוחרים תזכורת ב"תזכורת שבועית", ושומרים.
2. "שליחת תזכורת לניסיון" שולחת מיד לטלפון ו/או למייל. ההודעה אומרת מה נשלח ומה לא.
3. תזכורת לא נשלחת למי ששלחה כבר את המבט לשבוע הזה, לא בשבוע שסומן "דילוג", ולא פעמיים באותו יום.
